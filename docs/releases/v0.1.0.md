# LLSU v0.1.0

LLSU jointly models underwater image formation, low-light enhancement, and scene
geometry with 3D Gaussian Splatting.

This source release includes:

- The Nerfstudio implementation and CUDA rasterizer.
- 11 underwater scene configurations with a shared dataset layout.
- Training, evaluation, and rendering commands, installation instructions, and
  GPU memory recommendations.
- Source checks, packaging checks, and license notices.

See the [README](https://github.com/booqo/lowlight-underwater-for-nerf-studio#readme)
for installation and usage, and the
[LLSU article](https://ieeexplore.ieee.org/abstract/document/11663292) for method
details and experimental results.

The source archive includes a file-level SHA-256 manifest. A separate checksum
file is provided for the archive. Download datasets separately and follow the
training instructions to generate checkpoints.

Full training validation on a second machine is pending for this release.
